🎒 Campus Lost & Found System – Backend
📌 Project Overview

The Campus Lost & Found System is a backend application designed to help students report, track, and recover lost items within a campus environment. The system provides secure APIs for item reporting, searching, matching, and status updates.

This project focuses on backend logic, data modeling, and real-life workflow implementation.

⚙️ Tech Stack

Node.js

Express.js

MongoDB & Mongoose

JavaScript

JWT Authentication

REST APIs

Git & GitHub

✨ Features

User registration and authentication

Secure item reporting (lost & found)

Item matching and status updates

User dashboard APIs

Structured database models

Secure and scalable backend architecture
